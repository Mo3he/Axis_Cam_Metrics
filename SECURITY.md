# Security Policy

This is an independent, community-developed ACAP package. It is not an official
Axis Communications product and is provided on a best-effort basis.

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories or by
emailing <moshe@mohome.net>. Include the affected version, camera model and AXIS OS
version, impact, and reproduction steps. Do not publish credentials, API keys, or
camera passwords in an issue.

## Scope

The ACAP entry binary, configuration handling, settings endpoint, web UI, and
packaging are in scope. Vulnerabilities in bundled upstream components should
also be reported to their respective projects.
